# Informasi Login Admin — Reka Limbah

> **RAHASIA** – Jangan bagikan file ini ke publik atau unggah ke repositori publik.

## Akun Administrator

| Field     | Nilai      |
|-----------|------------|
| Username  | `admin`    |
| Password  | `admin123` |
| Role      | Admin      |

**URL Login:** Klik tombol **Login** di pojok kanan atas navbar, lalu masukkan kredensial di atas.

## Setelah Login

Setelah berhasil masuk sebagai admin, Anda akan diarahkan otomatis ke halaman **Dashboard Admin** (`/admin`).

Di halaman admin Anda bisa:
- Mengelola produk (tambah, edit, hapus)
- Melihat dan menghapus pesan masuk dari formulir kontak

## Catatan

- Kata sandi disimpan secara lokal (client-side) untuk keperluan demo/capstone.
- Untuk produksi nyata, gunakan autentikasi berbasis server dengan enkripsi password.
